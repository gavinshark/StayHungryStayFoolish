# 交付自检

交付前逐项勾选；任何未通过项先修复，或把无法修复的缺口写入正文并说明影响。

- [ ] 五章齐全且顺序正确：背景 / 现状 / 需求 / 方案选型（或方案） / 参考链接；没有未经确认的新增一级章节
- [ ] 第四章模式与用户要求一致：选型模式至少 3 个候选并评分；方案模式已写基础内核、各阶段职责、风险与验证计划
- [ ] 来源清单确认 Gate 已完成，5.9 记录确认日期、用户增删意见和后续新增来源
- [ ] AI Code Review/Agent 主题覆盖默认六簇；其他主题有 4-6 个同等级实践簇，并在 2.1.0 说明映射和证据状态
- [ ] 每个有直接证据的实践对象都有六段实践卡和至少 2 个可追溯来源；不适用对象仍保留六段标题并逐项说明原因
- [ ] 每个实践卡的字段都有来源或明确写“未公开/待确认”；效果包含口径、基线、时间范围、归因和验证方
- [ ] 规划已标注“公开规划 / 报告建议 / 未公开或待确认”，没有从当前架构外推厂商路线图
- [ ] 没有用 star、营销表述、评论数量或推断替代效果指标
- [ ] 每个有直接证据的实践簇都有代表性图片或“暂无可公开复用图片”说明；图片、来源、许可与主张可回溯
- [ ] 每张图有 `图 <章节号>-<序号>：<标题>` 图注；编号在最小小节内连续；重排后已重算
- [ ] 除 Mermaid 外，图片均引用能打开的本地相对路径；只有下载失败项使用远程外链并标注“原图链接”
- [ ] 华泰现状没有编造；缺失项标明待补充内容和责任人
- [ ] 修改“现状/流程/能力”类事实后，已全库搜索同类表述，背景、导语、表格与摘要同步更新
- [ ] 公开展示稿未出现“据用户提供/内部材料显示”等来源披露措辞；内部底稿保留来源属性，内部材料已获公开授权或从公开版移除
- [ ] 公开稿前四章的统计免责声明已压缩，样本、变量、模型、基线和归因边界记录在第五章或研究底稿
- [ ] 需求包含角色、触发、流程、成功标准和 P0/P1/P2，不只列功能
- [ ] 选型模式至少比较 3 个方案，维度与权重一致，推荐结论有理由、改变条件和风险；方案模式保留同样的风险与验证要求
- [ ] 所有来源集中在第五章；前四章只有内联引用，没有“本章来源”或分散来源清单
- [ ] 事实、推断和建议分开；关键数字有出处、日期和版本
- [ ] 若存在 MD→HTML 构建脚本，已重跑并验证标签闭合与图片相对路径可解析
